# 硬件选型对比：ESP32-S3-Touch-LCD-4B vs ESP32-P4-WIFI6-Touch-LCD-4B

> 面向「威思客桌面 AI 助理 × 桌面电子工牌」的选型结论
>
> 版本：v1.1 · 2026-10-26 · 对应方案 [virsical-desktop-ai-badge-architecture.md](virsical-desktop-ai-badge-architecture.md)
>
> **v1.1 变更**：一期所有硬件不做电池，桌面固定外接供电。电池不再作为差异项，评分与结论已重算。

---

## 1. 结论先行

**一期（30–50 台、6–8 周）默认仍选 ESP32-S3-Touch-LCD-4B（8.2 分），但领先已从 1.5 分缩到 0.6 分；如果 720×720 屏幕已签样，直接上 P4-4B（31416），不要做两代硬件。**

| 方案 | 得分 | 定位 |
|---|---|---|
| **ESP32-S3-Touch-LCD-4B（32052）** | **8.2 / 10** | 480×480 工牌方案的默认选择：板级、供应、成本、单芯片都最稳 |
| ESP32-P4-WIFI6-Touch-LCD-4B（31416） | 7.6 / 10 | 720×720 + 双麦 + 摄像头；屏幕规格一旦升到 720p，它就是更合适的长期平台 |
| ESP32-P4-86-Panel-ETH-2RO（31570） | 5.8 / 10 | 墙面工程面板；有线网口是唯一独占优势，桌面工牌不适用 |

**一句话**：去掉电池后，P4 的最大短板（无电池）消失，只剩 IMU、供应和双芯片成本；**480p 能签样就用 S3-4B，要 720p 就直接 P4-4B**，不要在试点期先做一版 480p 再迁移。

---

## 2. 约束变化：不做电池，固定外接供电

| 项 | v1.0（含电池） | v1.1（固定供电） |
|---|---|---|
| 功耗/续航 | S3 可脱离电源移动，P4 必须常接 | **不再是差异**：两台桌面机都 USB-C 5V 常供 |
| 电源管理 | S3 的 AXP2101 + 锂电是产品能力 | AXP2101 只作板上电源路径；不做电量 UI、不做充放电策略 |
| IMU 价值 | 拿起/移动唤醒、在场检测 | **下降**：设备固定在桌面不移动；在场判定应改由交互/日程/可选传感器提供 |
| P4 的短板 | 无电池、无 IMU | **只剩无 IMU**（可外挂或不做），产品匹配分从 6.5 升到 8.0 |
| P4-86Panel 供电 | DC 6–30V 是硬伤 | 电气上不再是问题，但 86 底盒 + 接线端子仍是**机械/施工**问题 |

**随之新增的工程要求（与板级无关，固件侧）**：断电重启自恢复、看门狗、RTC 纽扣电池走时、上电后快速重连（Wi-Fi + 双 MQTT）、无电池时的低功耗策略不再需要。

## 3. 硬件对照

| 项目 | S3-4B（32052） | P4-4B（31416） | P4-86Panel（31570） |
|---|---|---|---|
| SoC | ESP32-S3 双核 240MHz | ESP32-P4 双核 400MHz + LP 核 | 同 31416 |
| 屏幕 | 4" 480×480 RGB（ST7701） | 4" 720×720 MIPI DSI | 4" 720×720 MIPI DSI |
| 内存/存储 | 8MB PSRAM / 16MB Flash | 32MB / 32MB | 32MB / 32MB |
| 无线 | Wi-Fi 4 2.4G + BLE5 | Wi-Fi 6（C6 协处理器，SDIO）+ BLE5 | 同 31416 |
| 有线 | — | — | RJ45 百兆 + RS485 + 2 路继电器 |
| 供电 | USB-C 5V（板上保留锂电接口，一期不用） | USB-C 5V | DC 6–30V（底板） |
| IMU | QMI8658 六轴 | 无（可外挂） | 无（可外挂） |
| RTC | PCF85063 + 电池座 | 内置 + 电池座 | 内置 + 电池座 |
| 摄像头 | 无 | MIPI CSI（OV5647 已适配） | 未装配 |
| 结构 | 单板，桌面/壁挂，86 盒孔位 | 单板，可配桌面底座 | 主板 + 86 底盒底板 |
| 本仓库固件 | 已支持（目标板） | 通用 4B 变体已支持 | 无板级支持 |

> 供电一行是 v1.1 的关键变化：S3 与 P4-4B 在桌面场景下都是 USB-C 5V，电源不再是选型依据。

## 4. 按工牌需求逐项对照

| 需求 | S3-4B | P4-4B | P4-86Panel |
|---|---|---|---|
| 4" 方形工牌 UI | ✓ 480×480 已定义 | △ 720×720 重做 | △ 720×720 重做 |
| 免提语音 + AEC | ✓ 已验证 | ✓ 双麦更强 | ✓ 双麦更强 |
| 会议提醒 / 推送 | ✓ 已跑通 | ✓ 已跑通 | ✓ 已跑通 |
| 在场检测 | ✓ 板载 IMU（固定桌面后价值下降） | △ 可外挂 | △ 可外挂 |
| 720p 高分辨率 | ✗ 480×480 | ✓ 720×720 | ✓ 720×720 |
| 桌面部署 | ✓ USB-C 5V | ✓ USB-C 5V | ✗ 底盒 + DC 接线 |
| 有线网络 | ✗ 仅 Wi-Fi | ✗ 仅 Wi-Fi | ✓ RJ45 |
| 6–8 周试点 | ✓ 低风险 | △ 新 UI + 交期 | ✗ 新板级 |
| 后续加摄像头 | ✗ 无 CSI | ✓ MIPI CSI | ✗ 未装配 |

**计数**：S3-4B 原生满足 6 项，P4-4B 5 项；P4 赢在 720p 与摄像头，S3 赢在 IMU、板级与试点周期。

## 5. 加权评分（v1.1）

权重不变：产品匹配 35%、交付风险 25%、成本交期 15%、语音 15%、扩展 10%。

| 维度（权重） | S3-4B | P4-4B | P4-86Panel |
|---|---|---|---|
| 产品匹配（35%） | 8.5 | 8.0 | 5.5 |
| 交付风险（25%） | 9.0 | 7.0 | 5.0 |
| 成本与交期（15%） | 9.0 | 6.5 | 5.0 |
| 语音体验（15%） | 7.5 | 8.5 | 8.5 |
| 可扩展性（10%） | 5.0 | 8.0 | 6.0 |
| **加权总分** | **8.2** | **7.6** | **5.8** |

> 评分是内部相对判断。v1.0 → v1.1：S3 从 8.4 降到 8.2（电池优势消失），P4-4B 从 6.9 升到 7.6（无电池不再是短板），86Panel 从 5.6 升到 5.8（DC 供电不再是硬伤）。

**0.6 分差距来自哪里**：供应（P4-4B 国内商城当前缺货）、双芯片运维（P4 + C6、双 OTA）、成本（P4 约 1.5–2 倍），而不是屏幕或算力。

## 6. 仍不选 86 Panel 的原因

电池移除后，86 Panel 的供电劣势消失，但以下六件事仍然存在：

1. **固件零支持**：网口 / RS485 / 继电器 / DC 供电在本仓库没有任何板级代码，要新建板级、分区与固件身份。
2. **双芯片运维**：P4 + C6 两套固件、两条 OTA、SDIO 链路跨芯片定位。
3. **配网退化**：P4 不能用 BluFi（构建脚本已排除），只能热点配网。
4. **硅片与供应**：Rev<3 / Rev≥3 两套产物名；国内商城 4B 当前缺货，交期需先锁。
5. **UI 重做**：720×720 的布局、字阶、手势要重写，480×480 的验收标准同步作废。
6. **补齐硬件**：外挂 IMU、桌面结构件、DC 走线——把算力优势换成集成工作量。

**结论**：86 Panel 的价值在「会议室门口屏 / 工位控制面板」（网口 + RS485 控灯 + 继电器），不在桌面工牌。

---

## 7. 什么时候改选 P4-4B（31416）

出现以下任意一条，就直接选 P4-4B，不要先做 480p 版本：

- **720×720 已进入屏幕签样**，或 UI 要求高密度卡片 / 高清头像 / 二维码；
- 双麦远场语音、60fps 动效、视频播放成为一期验收项；
- 摄像头（人脸/工位占用）进入 12 个月路线图；
- 希望一次到位、不做二代硬件迁移。

选 P4-4B 需要同时接受三件事：外挂 IMU（或去掉 IMU 相关功能）、确认交期、承担 P4 + C6 双芯片运维。

---

## 8. 决策建议

1. **先回答一个问题：480×480 能不能签样？**
   - 能 → 一期 S3-4B，30–50 台、6–8 周，按 480×480 方案推进；
   - 不能 / 要 720p → 直接 P4-4B（31416），UI 一次做到 720×720，跳过 480p 版本。
2. **86Panel 单独立项**：会议室门口屏（网口 + RS485 + 继电器），不与桌面工牌共用固件身份。
3. **固定供电的固件要求**：断电重启自恢复、看门狗、RTC 走时、上电快速重连；不做电量 UI。
4. **验收（真机）**：480×480（或 720×720）UI 帧率与 1m 可读性、语音往返时延与唤醒率、会议室噪声下 AEC 识别率、IMU 在场判定准确率（如保留）、断电重启恢复时间与看门狗复位、72h 在线率与断线重连。
