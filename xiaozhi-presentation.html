项目概述

🎯 项目定位

XiaoZhi 是一个开源的 ESP32 语音助手固件，支持多种芯片、显示屏、音频设备和网络传输方式，通过 WiFi 连接云端 AI 实现语音对话。

🏗️ 架构特点

板级抽象设计，一套核心代码支持多种硬件；通过 OTA 服务器配置协议（MQTT/WebSocket），设备激活后即插即用。

🌐 服务集成

连接云端 AI 服务，支持语音识别（ASR）、大语言模型对话（LLM）、语音合成（TTS），以及 MCP 工具调用。

🔧 本项目定制

基于 Waveshare ESP32-S3-Touch-LCD-3.49 v2 开发板，定制了屏幕旋转、电池监控、IMU 姿态唤醒、主题切换等功能。

显示系统：屏幕旋转

🎯 需求

原厂屏幕为 172×640 竖屏，物理按钮在下方会遮挡 UI。需要旋转为横屏显示，按钮朝上。

⚙️ 实现方案

  • LVGL 软件旋转 270°
  • 逻辑分辨率变为 640×172 横屏
  • lv_display_set_rotation(LV_DISPLAY_ROTATION_270)
  • flush 回调用 lv_draw_sw_rotate 旋转缓冲区

📐 坐标变换

// 旋转前（竖屏） ┌──────────┐ │ │ 172 宽 │ LCD │ │ │ │ │ 640 高 └──────────┘ // 旋转 270° 后（横屏） ┌──────────────────────────┐ │ │ │ LCD │ 172 高 │ │ └──────────────────────────┘ 640 宽 // 按钮从下方移到上方

UI 使用 LV_HOR_RES/LV_VER_RES 动态宏，自动适配旋转后的分辨率。

IMU 姿态唤醒

🎯 功能描述

通过 IMU 检测设备姿态变化，抬手或翻转设备自动进入聆听模式，无需按按钮或说唤醒词。

⚙️ 实现参数

参数值
传感器QMI8658
接口I2C（音频总线共用）
采样率5Hz
触发阈值0.1g（极灵敏）
冷却时间5 秒

🔄 工作流程

计算合成加速度
↓
变化量 > 0.1g?
↓ 是
检查冷却时间
↓ 通过
ToggleChatState() 进入聆听

使用 ToggleChatState() 而非 StartListening()，确保 AutoStop 模式说完话自动退出。

语音唤醒：自定义唤醒词

🎙️ 唤醒词配置

"你好小威"

拼音：ni hao xiao wei

⚙️ 技术方案

  • 模式：MultiNet 自定义唤醒词
  • 模型：ESP-SR Multinet
  • 阈值：20（1-99，越小越灵敏）
  • 配置：NVS 持久化

📋 AFE vs MultiNet 对比

特性AFE WakeNetMultiNet
唤醒词固定（你好小智等）任意拼音
识别精度高中等
打断 AI✅ 支持❌ 不支持
资源占用高低

本项目选择 MultiNet 以支持自定义唤醒词"你好小威"，代价是不能打断 AI 回复。

网络协议架构

📡 MQTT 协议（默认）

控制通道：MQTT publish/subscribe

音频通道：UDP + AES-CTR 加密

默认端口：8883（TLS）

心跳：90 秒 ping

重连：60 秒自动重连

MQTT 用 UDP 传输音频以降低延迟，控制指令用 MQTT 保证可靠性。

🌐 WebSocket 协议

控制通道：WebSocket text frame

音频通道：WebSocket binary frame

默认端口：443（TLS）

单连接：文本+音频共用

WebSocket 单通道更简单，但音频延迟略高于 UDP。

OTA 与设备激活

📋 激活流程

  1. 设备连接 WiFi
  2. 请求 api.tenclass.net/xiaozhi/ota/
  3. 服务器返回配置：
    • MQTT/WebSocket 地址
    • 激活码（首次）
    • 服务器时间
    • 固件版本信息
  4. 写入 NVS 持久化
  5. 显示激活码给用户
  6. 用户在 App 输入激活码
  7. 激活完成，进入 idle

⚡ 性能优化

跳过版本检查（已实现）

检测 NVS 已有 MQTT/WebSocket 配置时，直接跳过 OTA 版本检查循环，大幅加速启动。

停用固件升级（已实现）

注释掉 UpgradeFirmware() 调用，防止服务器远程推送固件升级，保留配置获取和激活功能。

技术亮点

🎨 LVGL 软件旋转

不依赖硬件旋转，通过 lv_draw_sw_rotate 在 flush 回调中实时旋转帧缓冲区，支持任意角度。

🤸 IMU 姿态触发

复用音频 I2C 总线连接 QMI8658，5Hz 采样，0.1g 阈值，无需额外 GPIO。

⚡ 快速启动

NVS 配置缓存，跳过 OTA 版本检查，已激活设备秒级进入待机状态。

🔒 加密音频

UDP 音频流使用 AES-CTR 加密，PSA 加密 API，防止音频被窃听。

🎭 双主题系统

Light/Dark 主题完整切换，LVGL 事件冒泡实现双击切换，NVS 持久化。

🔋 电池集成

ADC 分压采样，状态栏自动显示电量，低电量弹窗保护。
